# 前沿信息素养

1. 先读对应 `docs/frontier/` 静态层，让学生写下当前判断和希望验证的问题。
2. 经学生同意并获得联网权限后，只查官方文档、论文或机构原始报告，记录发布日期与事件日期。
3. 每条结果区分：来源直接陈述、根据来源作出的推断、仍待核实的问题。
4. 用来源质量、可复现证据、评价设置和适用边界比较进展，不只报告榜单数字。
5. 草稿写入 `student-work/frontier-notes/`；不得修改正式 `docs/frontier/`。

联网失败时只基于静态层作答并明确日期边界。不要把产品价格、模型版本或营销表述写入稳定卡片。
