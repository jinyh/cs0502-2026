# 实验 01：典型数据结构

先在 PAI-DSW 快速开始 Notebook 中运行 `init_lab("lab-01-structures")` 创建学生副本。预测三个公开测试分别会检查什么，再编辑 `student-work/labs/lab-01-structures/solution.py`：

1. `is_balanced(text)`：用栈检查三类括号。
2. `hanoi_moves(n)`：返回汉诺塔移动序列，`n=0` 返回空列表。
3. `serve_by_priority(tasks)`：使用堆按 `(优先级, 名称)` 顺序返回任务名。

验收：公开测试通过；能解释每个结构的访问规则和复杂度；至少补一个边界测试。
