汉诺塔：把同一个问题逐层拆小

先理解三个子任务，再展开递归，观察调用栈怎样保存未完成的工作。

先预测：要把最大的盘从 X 搬到 Z，上面的盘必须先放到哪里？最大的盘搬好后，还剩下什么任务？

圆盘的位置

金色标出刚移动的盘；灰色圆盘属于外层任务。圆盘的位置过渡只表示状态变化。

每次调用都执行同一段过程

Hanoi(n, 源柱, 辅助柱, 目标柱)
  1. 若 n = 0：立即返回
  2. ① Hanoi(n−1, 源柱, 目标柱, 辅助柱)
  3. ② 将盘 n 从源柱移到目标柱
  4. ③ Hanoi(n−1, 辅助柱, 源柱, 目标柱)
  5. 本次任务完成，返回调用者

调用栈：返回后接着做什么

栈顶在上方。外层任务暂停，等待子任务完成。

递归的关键：把 n 个盘的任务交给两个 n−1 个盘的同类任务，中间只亲自移动一次最大盘。每次调用的规模减 1，最终到 n=0 返回。返回后从保存的位置继续。X、Y、Z 是固定柱名，“源、辅助、目标”是每次调用中的角色。
