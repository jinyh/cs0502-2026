# 可视化（code/visualizations/）

自包含 HTML 交互可视化（内嵌 CSS+JS，单文件，浏览器直接打开）。迁移自课程 Demo，原文件保留在教师工作区。

## 清单与对应卡片

| 文件 | 主题 | 对应卡片 | 嵌入方式 |

| `binary_heap.html` | 二叉堆的插入与下沉 | `04-data-structure-basics` | iframe 或新标签打开 |
| `circular_queue.html` | 循环队列的入队出队 | `04` / `05` | 同上 |
| `Hanoi.html` | 汉诺塔递归过程 | `07-greedy-algorithm`（递归） | 同上 |

## 使用

直接在浏览器打开任意 `.html`，或在卡片 Markdown 中以相对路径链接（如 `[二叉堆可视化](binary_heap.html)`）。OpenCode 智能体可在回答中给出路径让学生打开。
