## 课堂讲法（约 4–5 分钟串联 P28–P34）

1. **P28 八小区 K-Means（`#kmeans`）**：
   - 先停在初始中心 `A(1,1)` 与 `E(9,1)`，请学生预测 `D(1,9)` 分给谁；点击「揭示分配 →」显示垂直平分线（Voronoi 分界）与平方距离，再点击「揭示新中心 →」验证均值 `(1, 5)` 与 `(9, 5)`、总 `SSE = 100`。
   - 切到「初值 A, D」，用相同 8 个点跑完收敛，对比南北分组、中心 `(5, 1.5)` 与 `(5, 8.5)` 以及更高的 `SSE = 130`，直接说明 **K-Means 对初始中心敏感、可能陷入局部最优**。
   - 如有时间，顺带切到「离群点拉偏中心（P29）」，展示单个极端点 `I(9.5, 9.5)` 把中心从 `(6, 6)` 拉偏到 `(6.7, 6.7)`。
2. **P30 层次聚类与系统树图（`#hierarchical`）**：
   - 用默认的六点案例 `A–F` 连续点击合并，观察左侧包络框与右侧系统树图同步长出 `((A,B),(C,D))` 与 `(E,F)`，与课件 P30 一一对应；建树完成后拖动「保留簇数 k」滑块横切树图，一句话讲清“一次凝聚、多尺度切割”。
   - 课后拓展或答疑可切到「平行双条带」，把组间距离在 `Single（最短距离）` 与 `Complete（最长距离）` 间切换，在 `k = 2` 下直观看到横切与纵切的差异。
3. **P32–P33 DBSCAN 手算讲评（`#dbscan`）**：
   - 纸笔完成 P32 练习后打开默认预设（`ε = 2, MinPts = 3`，`d² ≤ 4` 含等号且计入自身），在三个关键暂停点快速核对：`B` 恰好 3 点且 `d²(A,B) = 4` 压线、`D` 仅 2 点被核心 `A` 吸收为边界点、`H` 为噪声点；再步进核心点链式扩张，呈现 `簇 1={A,B,C,D}`、`簇 2={E,F,G}`、`噪声={H}`。
   - 若学生追问“边界点会不会继续向外拉人或把两簇桥接起来”，直接切到第二个预设「边界点不扩张演示（`ε = 2, MinPts = 4`）」，指向 `E(5,3)` 与 `J(2,6)→K(2,8)` 即可当场澄清。
4. **P34 方法选择收束（`#compare`）**：
   - 默认进入「双弯月 + 散落噪声」，先保持预测遮罩提问，再点击「揭示三算法结果」同屏对照：K-Means 直线腰斩且强行吸收噪声、层次聚类 Average/Complete 切错而 Single 易把噪声单拆成簇、DBSCAN 准确分离双弯月并标记 `×` 噪声。
   - 最后务必切到 **「密度不均（DBSCAN 局限）」**，把 DBSCAN 的 `ε` 从 `0.85` 拖到 `2.00`：小 `ε` 把右侧稀疏簇全判成噪声，大 `ε` 又把左侧两密簇粘连在一起，而 K-Means 与 Average 层次聚类此时更稳健——由此收束核心结论：**算法背后的几何与密度假设决定它适合什么数据，没有万能算法**。

## 模型数据与边界

- **严格等比例画布**：所有平面散点图采用 X、Y 轴 1:1 像素比例，保证欧氏距离与 DBSCAN 的 `ε` 邻域圆在屏幕上保持正圆。
- **课件原题数据**：
  - K-Means P28：`A(1,1), B(1,2), C(1,8), D(1,9), E(9,1), F(9,2), G(9,8), H(9,9)`，与 `Slide14-DataMining1-2026` P28 一致。
  - DBSCAN P32：`A(2,2), B(2,4), C(3,3), D(0,2), E(8,2), F(8,4), G(9,3), H(5,6)`，`ε = 2`，`MinPts = 3`，采用欧氏距离平方 `d² ≤ 4`（含等号，邻域计入自身），与课件 P32–P33 及 `check_dm1.py` 口径完全一致。
- **教学构造数据**：对比模式的 5 套二维分布（双弯月、球形团、同心圆、离群点、密度不均）、层次聚类六点/双条带数据及 DBSCAN `MinPts = 4` 边界不扩张示例均为显式构造的教学模型，仅用于建立算法假设直觉，不代表真实采样数据。
- **边界点归属约定**：当同一边界点同时落入多个不同核心连通分量的 `ε`-邻域内时，页面按 Slide14 P31 伪代码“最强连接”（核心邻点数最多，平手取最近核心点与较小簇号）确定唯一归属，不做二次扩张。
- **关于决策树**：决策树属于有监督分类（需已知类别标签），将在 Slide15「数据挖掘二」单独讲解，不与本页无监督聚类混用。

## 操作与快捷键

- 对比模式：可切换 5 套分布、调节 `k` / 初值 / 链接准则 / `ε` / `MinPts`，或直接点击任意画布追加新点（三算法同步重算）；按 `Space` 可快速揭示/隐藏结果。
- 分步模式：`←` / `→` 单步回退或前进，`Space` 播放或暂停；DBSCAN 模式中点击图中任意点或表格行可单独检视其 `ε` 邻域与全部距离平方。
- 页面 `clustering-model` 脚本为界面与 `tests/test_clustering.py` 共用的唯一数学计算源。
