    课堂讲解与对照 · Slide05 第 24 / 31 页
    1. DFS：先看 A → B → D → C 的调用链。C 没有未发现邻居时，自动播放暂停：让学生预测弹出谁、恢复谁，再单步返回 D、进入 E。回到 D 不会再次加入首次发现序列。
    2. BFS：切换算法，从 A 开始。处理完 B 后自动暂停，此时队列为 [C, D]：C 先入队，所以先处理 C。检查 C 的邻居 D 时，D 已被标记，无须重复入队。
    3. 比较：DFS 的栈保存尚未结束的函数调用，包括返回后继续检查邻居的位置；BFS 的队列保存已发现、等待处理的顶点。DFS 的“返回”不是发现新顶点；BFS 的“出队”也不是首次发现。

    DFS = depth-first search（深度优先搜索）；BFS = breadth-first search（广度优先搜索）。栈（stack）后进先出；队列（queue）先进先出。BFS 的距离按边数计，只在无权／等权条件下对应最短距离。
