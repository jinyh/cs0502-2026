# RSA：课堂使用

[打开演示](rsa.html)，配合2026版Slide11 P24–26。单文件、自包含，可离线使用和全屏投影。

## 讲解顺序

1. 从“Bob生成密钥”开始，逐步揭示秘密素数3、11，模数33，辅助量φ(n)=20，公开指数7及秘密指数3。停在模逆元：7×3=21，除以20余1，不是普通倒数。
2. Bob公开公钥(7,33)，Alice收到公钥。橙色区域是教学视图中展开的Bob秘密信息，不表示这些数字经信道传递；公开公钥归属仍需认证。
3. 在加密预测处暂停，请学生猜余数。下一步揭示4⁷ mod33=16，再发送密文。接收方使用秘密指数3，预测并验证16³ mod33=4。
4. 修改明文数字并“应用明文”，复用同一密钥，从公钥已发布的状态开始。合法范围为0–32的整数。0、1以及部分其他数字可能加密后不变，运算仍能还原；这是小参数裸RSA的教学模型。
5. 传输密文后展开攻击者视角，依次分解公开的33、重建φ(n)及d、解密。该计算只取公开公钥和密文，不读取Bob的秘密参数。
6. 收束提问：任何人都能使用Bob公钥加密，Bob能因此确认发送者是Alice吗？不能。由此转到P27签名与身份认证。

“上一步”可回看；“从头演示”保留当前已应用明文并回到密钥生成起点。“逐次相乘取余”在完成加密后显示加密计算，在完成解密后改为解密计算；实际大指数采用高效模幂算法。

## 数学核心与边界

- n=pq，φ(n)=(p−1)(q−1)，选择e与φ(n)互质，求ed≡1 modφ(n)。公开(e,n)，保护d以及p、q；私钥表示也包含公开模数n。
- 加密c=mᵉ modn，解密m=cᵈ modn，合法消息代表值0≤m<n。页面验证所有33个合法数字，包含不与n互质的消息。
- 小数例子只说明正确性，不能保护实际数据。真实RSA需大参数、规范编码与填充以及可靠实现。分解n能够帮助求私钥，不声称RSA反演与整数分解已证明等价。
- 公钥加密不单独提供发送者认证。本页不把签名称为“私钥加密”，也不把教学参数或直接幂运算作为实际密码接口。

依据：[RFC 8017：RSA密码规范](https://www.rfc-editor.org/rfc/rfc8017.html)。页面`rsa-model`是界面与`tests/test_rsa.py`共用的数学计算源。
