## 实际发现与修正

1. 初次浏览器操作发现，阈值输入 81 后统计未即时更新。将有效数值更新绑定到 `input` 事件，并保留失焦校验；重新输入 81 后输出为 1。
2. SVG 不能依靠普通 HTML 元素的 `.hidden` 属性切换显示，导致最初的区域框和二维图没有出现。改为显式切换 `hidden` 属性；截图确认框和地图显示，二维主流程重跑通过。
3. 结构展开时标签拥挤、控制区偏低。减少默认浮动标签，对标签进行避让并约束显示边界，放大结构默认视角；任务控制移到场景上方，部件目录仍保留全部项目。
4. 原图显示与“曾查看区域”的记录最初共用一个标志，重新查看原图可能保留区域框。分开当前证据视图与已查看记录，复位同步恢复原图。
5. 将部件职责移到不依赖 Three.js 的 `parts.mjs`，避免三维库失效时同时丢失二维部件说明。
6. 库内 Markdown 链接检查把 `?view=2d` 当成文件名。修正查询参数处理，保留合法的二维入口；相关 30 项检查通过。
7. 补充引导的终止状态处理：返航或能量耗尽后都可进入报告复盘，不因候选路线遗漏 P2 而一直等待该点。

## 第二轮迭代：四种思维显式教学（2026-09-12）

起点是用户实际查看后的反馈：网站能演示无人船，但四种思维对导论学生过于隐晦。本轮对照课程蓝图 L01 的可观察目标，将主导航改为四种思维，原三个视角成为观察工具。每节提供定义、可检验问题、操作与概念的联系、解释输入和证据保存；新增跨工程场景的迁移自测。

实际浏览器检查：

- 计算思维：空规格得到表示、步骤与约束反馈；完整规格下选择直达路线仍提示禁区冲突；合规路线可以保存任务规格并出航。
- 系统思维：P1 自动切换学习单。四项预测填完后才开放课堂断网；故意预测“推进停止”仍可开展实验，之后修正为继续，原预测仍被保存。断网证据为 31 s 船上 2 / 岸站 1，补传证据为 32 s 船上 2 / 岸站 2。
- 数据思维：课堂模式在预测前隐藏统计和追踪输出。输入预测 1，标准样例实际得到 2，页面反馈边界检查；阈值改为 81 后重新隐藏结果，重新预测后显示 1。保存的数据说明包含来源、规则、预测和实际次数。
- 智能思维：先保留候选和验证方法，再打开 P2 图像；确认裂纹仍提示证据不足。查看原图、区域和补拍，选择进一步复检、补充结构检测计划后，允许保存判断修正过程。
- 四份学习成果实际保存，并在报告汇总；示例解释由开发代理填写作功能验证，不是学生作答或学习效果证据。
- 迁移题故意错答一项显示 3/4，修改后使用 Enter 检查得到 4/4；反馈说明各动作主要关注点，开放解释不自动评分。
- 新版课堂主线分别在三维和手动二维模式完成，均在 63 s 返航，岸站收到 3 条记录，生成注明 P2 待复检的教学报告。
- 最终版本自由探索的全部网页统计样例再次核对：1、1、0、2，阈值 81 得 1，严格 >80 得 1；程序 Enter 追踪、结构展开 70%、部件键盘选择、旋转、缩放与聚焦均可用。正常页面最终控制台警告/错误为空。
- 报告全文在网页中实际核对，包含四种思维、初始错误预测、断网与恢复时刻、自己的解释和迁移作答；另提供标准下载链接及可复制全文。内嵌浏览器接受了下载操作，但本轮没有确认新文件写入系统 Downloads，因此文件落盘不作为本轮通过项。

本轮修正记录：初次接入时渲染函数误递归，页面停留在三维加载状态；浏览器发现后修正并重载验证。移除与四项系统预测重复的通用预测选择；导航与成果区仅在内容改变时重建，避免航行更新反复替换键盘焦点。静态测试发现首页没有连续的“先预测”提示，补回明确的操作方式后通过。

新增 3 组教学规则测试后，Node 共 9 组通过；相关 pytest 仍为 30 项通过；实际 Python 五项对照通过。该结果验证程序行为，不等同课堂学习成效。

## 第三轮迭代：降低单屏复杂度（v1.2，2026-09-12）

用户指出单页同时呈现的知识点和操作过多，学生难以抓住重点。本轮将课堂模式改为“一屏一个问题、一个主要操作”，四种思维只作进度提示；操作结果出现后再用一句话解释概念。结构拆解、程序追踪和数据参数按需展开，完整工具保留在自由探索中。移除逐节长学习单和四道强制迁移题；结尾改为四张自动回顾卡和一个可口头讨论的迁移问题。

本轮实际验证：

- 课堂入口只显示当前路线问题、场景、候选与检查按钮。选择直达路线显示禁区冲突；第三路线显示覆盖 2/3；30 Wh 下合规路线显示预计剩余 -1.0 Wh。
- 三维课堂：错误预测“所有设备停止”也可开展断网；31 s 为船上 2 / 岸站 1 / 待交回 1，32 s 补传后为 2 / 2 / 0，63 s 完成返航。暂停点按共享状态触发，恢复通信单独停留展示补传结果。
- 按需展开的结构工具可用：展开 70%、键盘选择本地存储、旋转、放大、聚焦和职责说明；切到自由探索后原控件恢复。
- 二维课堂使用岸站指令配置完成：13 s 断网，18 s 检查点船位变化 0.0 m、船上与岸站各 1 条；恢复后不凭空产生补传记录，68 s 返航并生成带 P2 待复检结论的报告。
- 课堂数据先预测再揭示，错误预测 1 对照实际 2；改变数据或规则后重新预测。空记录显示“没有记录”，不推断设备正常。实际输入阈值的第一位 8、接着输入 1，展开区保持打开，焦点留在输入框，最终值 81 的结果为 1。
- 自由探索再次逐项核对 `[65,81]→1`、`[80]→1`、`[]→0`、`[65,80,81]→2`，完整样例阈值 81 返回 1。课堂中 `>80` 返回 1。实际 Python 五项验证一致；Python 逐句追踪可按需展开，Enter 可推进。
- 图像先显示原图与疑似区域，再要求保留候选；补拍后选择“已经确认结构裂纹”得到证据不足反馈。修正为进一步复检后报告可交，初始候选仍保留。
- 报告四张卡使用实际过程证据；数据卡最多显示最近两次比较，完整过程保留在报告全文。输入一个迁移复盘后，已核对它与初始错误预测一起进入报告。
- 重复点击当前课堂模式不会清空任务；从自由探索重新进入课堂恢复基准。参数设置集中在对话框，主要选择和操作可用 Enter；步骤切换将键盘焦点移到新问题。
- 1280×720 下主操作可完整显示，1440×900 入口和 390×844 窄屏入口经截图检查；窄屏课堂与数据工具的页面宽度均为 390，无横向溢出。正常三维和二维入口最终控制台警告/错误为空。

实际修正：去掉会提前透露答案的路线候选名称；修复改阈值时自动收起展开区的问题；保留选择按钮重绘后的键盘焦点；报告中的路线快照在出航时更新，避免更改电量后仍引用旧估算；未完成航次不将四个进度都显示为完成。

验证结果：Node 9 组状态与课堂检查点测试通过（包含实际 Python 对照），相关 pytest 30 项通过，MkDocs 严格构建通过。浏览器下载文件的落盘限制沿用第二轮记录，网页报告全文已核对。上述结果验证功能与布局，尚无学生课堂试用数据。
