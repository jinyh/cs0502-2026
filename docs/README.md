# 知识库主体（docs/）

本目录是「计算机科学导论」配套知识库主体，采用**混合方案**：21 讲轻量卡片 + 6 张扩展卡片 + 少数 AI 深度专题 + 前沿注记 + 多路径索引 + 脱敏考核支架。

- `cards/` — 21 讲轻量知识点卡片，一讲一页，编号对齐 `SlideNN`
- `deep/` — 高价值 AI 主题深度专题（LLM / 强化学习 / 量子计算等）
- `frontier/` — 前沿进展注记（静态写底 + 智能体联网增量双层）
- `paths/` — 多路径索引（思维支柱 / AI 能力 / 读者目标 / 跨学科桥接 / 工程问题求解）
- `assessment/` — 脱敏考核蓝图、项目 rubric 与个人学习进度 schema
- `glossary.md` — 全局术语表（中英对照）

设计原则：**卡片优先轻量，深度专题按需**。单卡片控制在约 300 行以内；主卡按“目标—核心概念—例子—误区—练习—代码/图”组织。讲稿原文 PDF 在课程 Canvas（不在公开仓库），本知识库是其“可检索、可运行、可迁移训练”的补层，而非替代。
