# 知识库主体（docs/）

本目录是「计算机科学导论」配套知识库主体，采用**混合方案**：21 讲轻量卡片 + 少数 AI 深度专题 + 前沿注记 + 多路径索引。

- `cards/` — 21 讲轻量知识点卡片，一讲一页，编号对齐 `SlideNN`
- `deep/` — 高价值 AI 主题深度专题（LLM / 强化学习 / 量子计算等）
- `frontier/` — 前沿进展注记（静态写底 + 智能体联网增量双层）
- `paths/` — 多路径索引（按思维支柱 / AI 能力 / 读者目标 / 跨学科桥接）
- `glossary.md` — 全局术语表（中英对照）

设计原则：**卡片优先轻量，深度专题按需**。单卡片控制在 ~300 行，深度内容强制入 `deep/`。讲稿原文 PDF 在 `../LectureNotes/`，本知识库是其「AI 时代补层」而非替代。
