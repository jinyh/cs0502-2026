# 考核训练层

本目录只保存**脱敏的能力与题型蓝图**，不保存历年题目、答案、学生作答或成绩。`reference/` 中的材料不得由课程智能体读取或改写。

- `blueprint.yaml`：教师填写并审核的题型、知识覆盖、认知层级、用时和评分点。
- `project-rubric.md`：课程项目过程性评审框架。
- `progress.schema.json`：学生明确同意后创建的本机 `student-work/progress.json` v2 结构；只含学习状态、提示次数、信心、错因标签和复习时间，不含身份、成绩或原始作答。

当前蓝图状态为 `template`。教师填入课程真实但脱敏的权重并改为 `approved` 前，`/mock` 只能生成“通用练习”，不得声称与正式考试等难。

## 学生命令

- `/practice <主题>`：一次一道全新变式，学生作答前不展示答案或评分点。
- `/mock <范围>`：只有蓝图获批且所有校准字段完整时按蓝图组卷；否则固定生成概念比较、状态追踪、代码调试、工程迁移四题“通用课程练习”，不标称正式权重、用时或难度。
- `/review <范围>`：同意本地记录后按到期时间和错因选题；没有到期项时不强行出题。
- `/exam-notes <范围>`：只整理已经练习或当场成功回忆的内容；已有笔记先预览、确认，再合并。
- `/project <student-work 路径>`：按 rubric 评审已有证据，不生成完整项目或报告。

本地进度和学生产物只写入被 Git 忽略的 `student-work/`。正式考试现场禁止继续使用 OpenCode。
