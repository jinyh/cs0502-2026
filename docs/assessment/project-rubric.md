# 课程项目过程性 Rubric

> 用于学生自查和智能体分级反馈。正式项目若有专用 rubric，以教师发布版本为准。

| 维度 | 达标表现 | 常见失分 |
|---|---|---|
| 问题与需求 | 用户、输入输出、约束、成功标准清楚 | 目标口号化、无法验收 |
| 设计与表示 | 数据结构、组件、接口及算法选择有理由 | 先写代码后补解释 |
| 实现与可读性 | 最小实现可运行，命名和注释服务理解 | 复制复杂代码但不能解释 |
| 测试与证据 | 正常、边界和失败路径均有可重复证据 | 只展示一次成功截图 |
| 分析与责任 | 说明限制、风险、AI 使用和改进方向 | 夸大结论、隐去 AI 贡献 |

OpenCode 可以逐项指出证据缺口、运行测试并提出下一步，但不生成可直接提交的完整项目或报告。
