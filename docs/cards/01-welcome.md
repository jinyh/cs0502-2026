# 课程导引（Welcome）

> 对应讲稿：`Slide01-Welcome-2025.pdf`（见课程 Canvas，不在公开仓库）

## 一句话定位

这门课不是“学会某一种编程语言”，而是建立一张计算机科学地图：问题怎样被表示、系统怎样协作、数据怎样产生知识、机器怎样表现出智能。

## 学完应能做到

- 用自己的话区分计算思维、系统思维、数据思维和智能思维。
- 面对一个工程问题，知道应先查哪几张卡片、做哪个实验。
- 正确使用 OpenCode：先预测和尝试，再获得分级提示；不把它当作作业或考试代答器。

## 课程地图

| 主线 | 核心问题 | 对应讲次 |
|---|---|---|
| 计算思维 | 什么能计算，怎样组织数据与算法？ | 02-08 |
| 系统思维 | 硬件、软件、网络与安全如何分层协作？ | 09-12 |
| 数据思维 | 怎样存储、发现并表达数据中的结构？ | 13-15 |
| 智能思维 | 怎样让机器从数据学习并完成感知、推荐与生成？ | 16-21 |

## 推荐学习闭环

1. 课后读一张卡片，先完成“主动学习与考核迁移”，再看代码。
2. 使用 `/learn 主题` 检查理解，使用 `/lab 编号` 完成代码实验。
3. 使用 `/practice 主题` 做全新变式题；错题记录在本机 `student-work/`。
4. 每周用 `/review` 主动回忆；考前用 `/mock` 和 `/exam-notes` 整理静态开卷资料。

## 考核与诚信边界

- 自生成练习：先作答，之后可以查看完整解析。
- 正在计分的作业和项目：智能体可以提示、测试和评审，但不提供可直接提交的完整成品。
- 正式期末：考场禁用 OpenCode，只携带课程规则允许的静态资料。
- 不向智能体提供学生名单、成绩、真实考题或其他敏感信息。

## 主动学习与考核迁移

1. 选一个本专业问题，说明它同时涉及哪两种思维支柱。
2. 写下你对“算法”“系统”“数据”“智能”四个词的当前理解，学期末再比较。
3. 给自己设定一个可检查目标，例如“能手工追踪 BFS”而不是“看懂图算法”。
