# 推荐系统（Recommendation System）

> 对应讲稿：`Slide19-RecommendSystem-2025.pdf`（见课程 Canvas，不在公开仓库）

## 一句话定位

推荐系统（recommendation system）在海量物品中为用户预测「可能喜欢什么」。它是数据挖掘（`14`）与机器学习（`17`）在电商、内容、广告场景的规模化应用。

## 核心知识点

### 为什么需要推荐

- 信息过载：选择太多，用户找不到，物品曝光不出。
- 长尾：热门靠排行就够，长尾靠个性化推荐。

### 主流方法

- **协同过滤（collaborative filtering, CF）**：找相似用户/物品。
  - 基于用户：「和你相似的人喜欢什么」。
  - 基于物品：「你喜欢的东西的相似物」。
- **基于内容（content-based）**：用物品特征匹配用户偏好画像。
- **混合（hybrid）**：结合上述 + 上下文。
- **深度学习**：用神经网络学用户/物品 embedding，捕捉非线性（如双塔模型）。

### 核心挑战

- **冷启动（cold start）**：新用户/新物品无历史数据。缓解：利用内容特征、跨域、引导。
- **数据稀疏**：用户只评过极少物品。
- **可解释性**：用户想知道「为什么推荐」。
- **探索 vs 利用（exploration-exploitation）**：只推已知的会信息茧房，需适度探索。

### 评估

- 离线：准确率、召回率、NDCG、覆盖率、多样性、新颖性。
- 在线：A/B 测试点击率/转化率。
- 单看准确率会推热门，损害多样性——需多指标。

## 直觉类比

| 概念 | 类比 |
|---|---|
| 协同过滤 | 问「和你品味相似的人最近读了什么」 |
| 内容推荐 | 「你读过人工智能的书，再推相关主题」 |
| 冷启动 | 新生刚入学，系统还不知道他喜好 |
| 探索-利用 | 餐厅：常点招牌（利用）还是试新品（探索） |

## 前沿进展注记

- LLM 推荐范式：用大模型做零样本推荐、可解释对话式推荐。
- 多目标：CTR + 长期满意度 + 公平性。
- 推荐 + Agent：智能体主动帮用户筛选而非被动排序。

## 跨学科联系

- 与医学：精准医疗可视为「给患者推荐最适方案」；健康教育内容个性化。
- 与心理/行为科学：推荐影响决策，关系信息茧房与成瘾。
- 与经济：推荐是平台经济的核心机制，关乎市场配置。

## 推荐交互式问答

1. 协同过滤和内容推荐各依赖什么数据？各何时失效？
2. 冷启动为什么难？有哪些缓解思路？
3. 只优化准确率为什么会害了推荐系统？（信息茧房/多样性）
4. LLM 推荐和传统协同过滤各有什么优劣？
