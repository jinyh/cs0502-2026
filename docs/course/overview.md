# 2026 秋季课程信息

CS0502「计算机科学导论」（Introduction to Computer Science）面向非计算机专业理工科及医学科学生。课程从计算、系统、数据和智能四条主线出发，帮助学生建立计算机科学的整体知识结构，并通过代码实验和跨学科场景理解概念如何落到真实问题中。

## 学习目标

完成课程后，学生应能：

1. 用计算思维把问题拆成可表示、可执行、可验证的步骤。
2. 解释程序、硬件、操作系统、网络和软件工程之间的基本关系。
3. 判断数据获取、组织、分析和可视化方法是否适合给定问题。
4. 理解人工智能与机器学习的核心思想，并识别评价、安全、伦理和责任边界。
5. 在医学、物理、生物和工程场景中迁移计算机科学概念。
