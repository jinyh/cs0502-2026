# 深度专题（docs/deep/）

承载少数高价值 AI 主题的深度内容。与 `cards/` 的区别：卡片一讲一页、~300 行上限；深度专题不限篇幅，可包含完整推导、代码与前沿展开。

## 选材标准

入选条件（满足其一）：
- AI 前沿变化快、卡片无法承载（如 LLM、强化学习）
- 跨讲稿主题，需要整合性视角（如量子计算虽非讲稿主线，但属计算范式变革）
- 对理工/医学科学生跨学科价值高
