# 量子计算基础深度专题（Quantum Computing）

> 对应卡片：[`08-turing-machine`](../cards/08-turing-machine.md)、[`12-information-security`](../cards/12-information-security.md)

量子计算利用叠加、纠缠与干涉等量子现象做计算。它**不打破丘奇-图灵论题**——可计算集合不变，但可能改变某些问题的复杂度。不同算法的加速幅度不同，不能把“量子”与“指数加速”画等号。

## 1. 经典 vs 量子：比特与量子比特

- 经典比特（bit）：确定 0 或 1。
- 量子比特（qubit）：状态 $|\psi\rangle=\alpha|0\rangle+\beta|1\rangle$，其中 $\alpha,\beta$ 是复振幅，$|\alpha|^2+|\beta|^2=1$。
- 有限类比：经典比特像已经落地的硬币；量子比特常被比作旋转中的硬币。但量子态由复振幅描述，类比不能表达相位与干涉。

### 叠加（superposition）

一个量子比特可同时「包含」0 和 1 的成分。但测量（measurement）会塌缩到 0 或 1，概率由 $|\alpha|^2,|\beta|^2$ 决定——**测量改变状态**，这是与经典最大不同。

### 纠缠（entanglement）

多个量子比特可处于不能写成各自独立状态乘积的联合态。对纠缠系统的测量结果可呈现超出经典局域模型的相关性，但不能借此实现超光速通信。纠缠是许多量子信息协议的资源。

## 2. 丘奇-图灵不变，复杂度可变

- 可计算性：量子图灵机与经典图灵机计算同样的函数集合。停机问题等不可判定性同样适用于量子计算。
- 复杂度：对特定问题，量子算法可能提供平方级或更强的渐近加速——这是它的价值所在，也是 [`08`](../cards/08-turing-machine.md) 提到的“复杂度维度变化”。加速类别必须针对具体问题和比较基线陈述。

## 3. 里程碑算法

### 3.1 Shor 算法（1994）

Shor 算法能在理想量子模型上以多项式时间分解大整数。已知最佳通用经典算法是亚指数时间而非指数时间；RSA 的安全性依赖大整数分解在实用参数下对经典计算仍然困难（关联 [`12`](../cards/12-information-security.md)）。
- 意义：足够大的量子计算机能破解 RSA/ECC → 推动后量子密码学（PQC）。
- 现状：现有量子机器远不足以分解实用规模的 RSA 密钥。

### 3.2 Grover 算法（1996）

无结构数据库搜索，$O(\sqrt{N})$ 加速。
- 意义：对对称密钥相当于减半安全位数（AES-256 → 约 128-bit 量子强度）。

### 3.3 量子模拟

模拟量子系统是量子计算的「原生应用」——Feynman 最初设想量子计算机就是因为经典机模拟量子系统太慢。这对化学/材料/药物发现意义重大。

## 4. 物理实现与挑战

- 多种候选平台：超导、离子阱、光量子、拓扑、中性原子。
- 共同挑战：**退相干（decoherence）**——系统与环境相互作用会抑制相位相干性；它不能简单等同于一次理想测量的“塌缩”。
- 量子纠错（QEC）：用多个物理量子比特编码一个逻辑量子比特，开销巨大。
- “NISQ”描述有噪声、尚不足以普遍容错的设备阶段；具体量子比特数量和纠错进展变化很快，应查阅带日期的一手资料。
- 某些实验已在特定采样或模拟任务上展示量子计算优势；优势是否可验证、可扩展并具有实际价值，需要按任务与成本逐项评价。

## 5. 与 AI 的关系

- 量子机器学习（QML）：理论上对某些线性代数运算加速，但实际受输入输出（数据加载）瓶颈限制。
- 目前没有已建立的、能普遍实用地加速 LLM 训练或推理的量子方案；数据装载、误差纠正和端到端成本都必须计入比较。
- 讨论量子机器学习时，应比较完整经典基线，而不是只比较某个理想化子程序。

## 6. 开放问题

- 能否造出容错量子计算机？纠错开销能否降到实用？
- 除了模拟与密码，还有多少实用量子优势问题？
- 量子优越性的「实用」边界在哪？

## 7. 跨学科联系

- **与物理/化学**：量子模拟是材料设计、催化、药物发现的核心工具——本专题对物理化学学生尤其相关。
- **与信息安全**：NIST 已于 2024 年发布首批三个后量子密码正式标准；现实系统仍需规划迁移、互操作和实现安全。
- **与计算理论**：BQP 等量子复杂度类扩展了经典复杂度的认知。
- **与哲学**：测量问题、实在性、定域性的长期争论。

## 8. 直觉类比

| 概念 | 类比 |
|---|---|
| 量子比特叠加 | 旋转硬币只能帮助想象“测量前不确定”，不能表达复振幅和相位 |
| 测量塌缩 | 打开薛定谔的箱子那一刻 |
| 纠缠 | 手套类比只能表示相关性，不能解释量子相关性为何超出经典局域模型 |
| 退相干 | 脆弱肥皂泡，一碰就破 |
| 量子加速 | “所有路径相消”是有限直觉；真正结论必须由具体算法、复杂度与测量概率支持 |

## 9. 常见误区

- 「量子计算机什么都快」——错，只对特定问题（如 Shor/Grover）有加速，很多问题无量子优势。
- 「量子计算打破丘奇-图灵论题」——错，可计算集合不变，只变复杂度。
- 「现在就能破解 RSA」——错，现有机器规模与噪声远不够。
