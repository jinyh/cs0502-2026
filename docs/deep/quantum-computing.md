# 量子计算基础深度专题（Quantum Computing）

> 对应卡片：[`08-turing-machine`](../cards/08-turing-machine.md)、[`12-information-security`](../cards/12-information-security.md)

量子计算利用量子力学现象（叠加、纠缠）做计算。它**不打破丘奇-图灵论题**——可计算集合不变，但在**复杂度**维度上对某些问题指数级加速。对物理/化学/材料学生尤为相关。

## 1. 经典 vs 量子：比特与量子比特

- 经典比特（bit）：确定 0 或 1。
- 量子比特（qubit）：状态 $|\psi\rangle=\alpha|0\rangle+\beta|1\rangle$，其中 $\alpha,\beta$ 是复振幅，$|\alpha|^2+|\beta|^2=1$。
- 直觉：经典比特是「硬币正反」；量子比特是「旋转中的硬币，落地才确定」。

### 叠加（superposition）

一个量子比特可同时「包含」0 和 1 的成分。但测量（measurement）会塌缩到 0 或 1，概率由 $|\alpha|^2,|\beta|^2$ 决定——**测量改变状态**，这是与经典最大不同。

### 纠缠（entanglement）

多个量子比特可处于不可分离的联合态，测量一个即时影响另一个（无论距离）。Einstein 称「鬼魅超距」，已被实验反复证实。纠缠是量子并行与量子通信的资源。

## 2. 丘奇-图灵不变，复杂度可变

- 可计算性：量子图灵机与经典图灵机计算同样的函数集合。停机问题等不可判定性同样适用于量子计算。
- 复杂度：对特定问题，量子算法可能指数级快——这是它的价值所在，也是 [`08`](../cards/08-turing-machine.md) 提到的「复杂度维度突破」。

## 3. 里程碑算法

### 3.1 Shor 算法（1994）

多项式时间分解大整数。对经典最快的算法是指数级——这正是 RSA 安全性的根基（关联 [`12`](../cards/12-information-security.md)）。
- 意义：足够大的量子计算机能破解 RSA/ECC → 推动后量子密码学（PQC）。
- 现状：现有量子机器远不足以分解实用规模的 RSA 密钥。

### 3.2 Grover 算法（1996）

无结构数据库搜索，$O(\sqrt{N})$ 加速。
- 意义：对对称密钥相当于减半安全位数（AES-256 → 约 128-bit 量子强度）。

### 3.3 量子模拟

模拟量子系统是量子计算的「原生应用」——Feynman 最初设想量子计算机就是因为经典机模拟量子系统太慢。这对化学/材料/药物发现意义重大。

## 4. 物理实现与挑战

- 多种候选平台：超导、离子阱、光量子、拓扑、中性原子。
- 共同敌人：**退相干（decoherence）**——量子态极脆弱，环境噪声使其迅速塌缩。
- 量子纠错（QEC）：用多个物理量子比特编码一个逻辑量子比特，开销巨大。
- 当前处于 NISQ（Noisy Intermediate-Scale Quantum）时代——百千量子比特、有噪声、无纠错。
- 量子优越性（quantum advantage）：已对特定人造任务展示，但无实用价值。

## 5. 与 AI 的关系

- 量子机器学习（QML）：理论上对某些线性代数运算加速，但实际受输入输出（数据加载）瓶颈限制。
- 量子计算不直接加速 LLM 训练——LLM 瓶颈是数据与梯度传播，非量子原生优势。
- 量子计算与经典 AI 各有适用域，目前是互补而非替代。

## 6. 开放问题

- 能否造出容错量子计算机？纠错开销能否降到实用？
- 除了模拟与密码，还有多少实用量子优势问题？
- 量子优越性的「实用」边界在哪？

## 7. 跨学科联系

- **与物理/化学**：量子模拟是材料设计、催化、药物发现的核心工具——本专题对物理化学学生尤其相关。
- **与信息安全**：后量子密码标准化（NIST PQC）是当下进行时。
- **与计算理论**：BQP 等量子复杂度类扩展了经典复杂度的认知。
- **与哲学**：测量问题、实在性、定域性的长期争论。

## 8. 直觉类比

| 概念 | 类比 |
|---|---|
| 量子比特叠加 | 旋转中的硬币，落地才定 |
| 测量塌缩 | 打开薛定谔的箱子那一刻 |
| 纠缠 | 一对手套分放两地，看一只即知另一只 |
| 退相干 | 脆弱肥皂泡，一碰就破 |
| 量子加速 | 不走直线而走所有路再相消——只对能利用干涉的问题有效 |

## 9. 常见误区

- 「量子计算机什么都快」——错，只对特定问题（如 Shor/Grover）有加速，很多问题无量子优势。
- 「量子计算打破丘奇-图灵论题」——错，可计算集合不变，只变复杂度。
- 「现在就能破解 RSA」——错，现有机器规模与噪声远不够。
