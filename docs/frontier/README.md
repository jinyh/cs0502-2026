# 前沿进展注记（docs/frontier/）

AI 前沿变化快，写死在卡片里会迅速过期；纯靠智能体联网又可能产生未经审校的失真内容。本目录采用**双层机制**：

1. **静态写底层**（人工审校，季度更新）— 可作引用依据
2. **智能体联网增量区**（动态，每条标注检索日期 + 来源 URL，未经审校）— 学生批判性阅读

## 选材阈值

仅对高变动主题建前沿页：`21-llm`、`16-artificial-intelligence`、`17-machine-learning`、`18-computer-vision`、`20-speech-recognition`、`deep/reinforcement-learning`、`deep/quantum-computing`。

基础稳定主题（数据结构、图灵机、网络协议）**不建**前沿页，避免噪声。

## 智能体约定

见 `../opencode/AGENTS.md`「前沿检索」一节：
- 询问「最新/进展/2026」时，先读本页静态层作底，再联网检索近 12 个月
- 结果以「一句话 + 来源 URL + 检索日期」追加到增量区，**不修改静态层**
- 联网失败 → 仅基于静态层作答并提示「未联网，信息可能不是最新」

## 模板

新前沿页复制 `_template.md` 起步。
