## 静态写底层（人工审校，季度更新）

### 2026 基线

- **架构主流**：decoder-only Transformer 主导；稀疏 MoE 普及以平衡容量与算力；长上下文窗口进入百万级 token。
- **对齐范式**：RLHF 与 DPO 并存；宪法 AI（Constitutional AI）等思路扩展；对齐税仍是开放问题。
- **推理模型**：显式长链思考（o1 类）在数学/编程任务大幅提升，代价是推理算力。
- **Agent 范式**：工具调用 + 记忆 + 规划成熟，多智能体协作与多模态 Agent 兴起。
- **多模态**：视觉/音频/动作统一到 token 序列，统一基座模型成为方向。
- **开源生态**：LLaMA 系列等开源模型缩小与闭源差距，本地部署普及。
- **效率**：量化（4-bit 推理）、推测（speculative decoding）、KV 缓存优化持续推进。

### 关键开放问题

- 幻觉能否根除，还是统计生成模型的固有属性？
- 长上下文「迷失中段」如何缓解？
- 训练数据枯竭后，合成数据与 self-improvement 的边界在哪？
- 涌现是真实现象还是评估指标的非线性？
- 推理模型的「思考」是真推理还是模式匹配的延伸？
