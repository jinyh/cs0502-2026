# 多路径索引（docs/paths/）

提供多条概念学习路径而非单一线性目录。每条路径串联若干卡片与深度专题，帮助学生按需导航；它们不代表课堂讲次顺序，21 讲正式序列见 [`docs/curriculum/`](../curriculum/README.md)。

- `by-thinking-pillar.md` — 按课程四大思维支柱：计算思维 / 系统思维 / 数据思维 / 智能思维
- `by-ai-capability.md` — 按 AI 能力形成路径：感知 → 学习 → 推理 → 生成 → Agent
- `by-reader-goal.md` — 按读者目标：医工 / 信工 / 材料 / 理科
- `by-discipline-bridge.md` — 按跨学科桥接：CS ↔ 医学 / 物理 / 生物
- `by-engineering-workflow.md` — 按工程链路：表示 → 算法 → 系统 → 数据 → 模型 → 验证

> 各路径只负责导航，概念定义以对应卡片为准，课堂学习结果以课程蓝图为准。
