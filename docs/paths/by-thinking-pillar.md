# 学习路径：按四大思维支柱

> 对齐课程大纲四大思维组织。每条支柱串联对应卡片，形成一条可顺序学习的路径。

## 计算思维（Computational Thinking）

把问题形式化为可计算步骤：抽象、分解、算法化。

1. [`02-intro-to-cs`](../cards/02-intro-to-cs.md) — CS 的边界与四大思维起点
2. [`03-programming-language`](../cards/03-programming-language.md) — 用形式语言下指令
3. [`04-data-structure-basics`](../cards/04-data-structure-basics.md) — 组织数据的方式
4. [`05-data-structure-advanced`](../cards/05-data-structure-advanced.md) — 搜索与哈希
5. [`06-graph-exploration`](../cards/06-graph-exploration.md) — 关系结构的遍历
6. [`07-greedy-algorithm`](../cards/07-greedy-algorithm.md) — 局部最优策略
7. [`08-turing-machine`](../cards/08-turing-machine.md) — 可计算性边界

## 系统思维（Systems Thinking）

理解分层、协议、协作——硬件到网络如何构成整体。

1. [`09-computer-system-arch`](../cards/09-computer-system-arch.md) — 冯诺依曼与存储层次
2. [`10-software-engineering`](../cards/10-software-engineering.md) — 复杂性的系统化管理
3. [`11-computer-network`](../cards/11-computer-network.md) — 分层协议互联
4. [`12-information-security`](../cards/12-information-security.md) — 安全作为系统属性

## 数据思维（Data Thinking）

从数据中提炼知识：存储、挖掘、呈现。

1. [`13-database`](../cards/13-database.md) — 结构化存储
2. [`14-data-mining`](../cards/14-data-mining.md) — 发现模式
3. [`15-data-visualization`](../cards/15-data-visualization.md) — 让数据可读

## 智能思维（Intelligence Thinking）

让机器学习与决策。

1. [`16-artificial-intelligence`](../cards/16-artificial-intelligence.md) — AI 范式与边界
2. [`17-machine-learning`](../cards/17-machine-learning.md) — 从数据归纳
3. [`18-computer-vision`](../cards/18-computer-vision.md) — 看懂图像
4. [`19-recommend-system`](../cards/19-recommend-system.md) — 个性化匹配
5. [`20-speech-recognition`](../cards/20-speech-recognition.md) — 听懂语音
6. [`21-llm`](../cards/21-llm.md) — 语言与 Agent 时代
7. 深度专题：[`llm-deep-dive`](../deep/llm-deep-dive.md) · [`reinforcement-learning`](../deep/reinforcement-learning.md)

> 四大思维并非割裂：图灵机（计算）是系统架构（系统）的理论基础；数据思维与智能思维共享统计学习根基。建议至少完成计算思维全段，再按兴趣深入其余。
