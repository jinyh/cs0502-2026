# CS0502 课程组核验清单

> 用途：课程组审议 21 讲教学安排、考核细目、课程项目和讲稿一致性。AI 已完成结构、代码、先修、图示和事实风险检查；本清单只保留必须由教师作出的教学与评价决策。

## 一、已经确认的课程约束

- [x] 总课时为 48 学时。
- [x] 42 学时用于 21 讲主题教学，每讲 2 学时。
- [x] 4 学时用于小组项目展示与个人答辩。
- [x] 2 学时用于课程综合复习。
- [x] 期末考试为纸质材料开卷。
- [x] 考试现场禁止电子资料、联网、OpenCode 和其他 LLM。
- [x] 总评构成：3 次作业 30%、小组课程项目 20%、期末考试 40%、课堂参与 10%。
- [x] 全学期安排 3 次正式计分作业，不按每周布置。
- [x] 8 个 Lab 默认用于形成性学习；只有教师在正式作业说明中明确指定时，才成为作业的一部分。
- [x] 项目评价同时考虑小组成果、个人答辩和个人贡献记录。
- [x] LLM 与 CV 两页前沿静态基线已经课程负责人审核通过。

- [ ] 21 讲的主题顺序与实际授课安排一致。
