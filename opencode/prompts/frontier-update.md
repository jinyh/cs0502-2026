# 提示词：前沿更新（frontier-update）

> 用法：学生想了解某 AI 主题最新进展时调用。遵循 `docs/frontier/` 双层机制。

## 模板

我想了解「<主题，如 LLM / 计算机视觉>」的最新进展。请：

1. 先读 `docs/frontier/<topic>-frontier.md` 的**静态层**，把当前基线讲给我。
2. 联网检索近 12 个月的相关进展（优先官方/一手来源）。
3. 把每条新进展以「一句话 + 来源 URL + 检索日期」格式追加到该 frontier 页的**增量区**（不修改静态层）。
4. 回答我时区分：哪些是稳定基线（静态层）、哪些是动态增量（未经审校，需我核实）。
5. 给我「如果只读三篇原始论文/报告，读哪三篇」的建议。

## 约束

- 联网失败时仅基于静态层作答，并明确提示「未联网，信息可能不是最新」。
- 不修改静态层（需人工审校）。
- 增量区内容标注日期与来源；不写未经核实的具体数字。
- 区分「刷榜数字」与「实际可用」，尤其在医学影像等场景。
