# 提示词：对照讲稿梳理（trace-lecture）

> 用法：学生想对照某讲讲稿整理脉络时调用。

## 模板

请对照讲稿 `<SlideNN-EnglishName>` 梳理本讲脉络。要求：

1. 先读 `docs/cards/<NN-*.md>` 获取本讲的卡片框架（核心知识点、直觉类比、跨学科联系）。
2. 用「为什么需要 → 核心是什么 → 怎么实现/应用 → 边界在哪」四段式重构本讲主线。
3. 标注本讲与前后讲稿的衔接（前置依赖、后续延伸）。
4. 列出本讲对非 CS 学生最该带走的两三个关键直觉。
5. 留 2 个思考题检验理解（不给答案，只给提示方向）。

## 约束

- 讲稿原文 PDF 在 `LectureNotes/`，引用文件名而非复制全文。
- 不替学生做讲稿里的作业题。
- 保持导论口径，不引入超纲形式化证明。
